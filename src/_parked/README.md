# Parked

Pages and components from the earlier, larger version of this site — the
research archive with recipes, regions, sources and the evidence-grading
apparatus.

They are **not routed and not imported**, so they do not affect the build.
They reference CSS classes that no longer exist in `src/index.css`, so they
will not render correctly if you re-route them as-is.

The data they were built on is all still live in `src/data/` and is untouched:

- `recipes.js`   — 21 dishes with ingredients, method, source and provenance
- `regions.js`   — 8 regions, pantries and what each one never had
- `corpus.js`    — 18 primary sources, what each gives and withholds
- `methods.js`   — technique essays (hulled grain, fat, souring, fire…)
- `fieldReports.js` — test-kitchen write-ups
- `kitchen.js`   — flavour, steering and nutrition notes per dish
- `sourcing.js`  — the three-tier ingredient substitution engine
- `grades.js`    — the four-grade evidence apparatus

Nothing here was deleted. Restore by moving a file back and adding its route.
